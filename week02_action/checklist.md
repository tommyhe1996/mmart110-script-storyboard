## 2.2 Create a Story from Action Verbs
- [ ] Watch *The Big House* ([YouTube Link](https://youtu.be/x3Cv6oIAaFA?si=q4J7u0TNM4qTX-9d))
- [ ] Write down observed actions (verbs)
- [ ] Choose 5 actions
- [ ] Arrange into 3 Acts
- [ ] Define protagonist (name + identity)
- [ ] Write short narrative (beginning, middle, end)

---

## 2.3 Learn Script Formatting
- [ ] Watch *Formatting Intro Video*
- [ ] Review *Standard Script Formatting.pdf*
- [ ] Take notes on sluglines, actions, spacing, etc.

---

## 2.4 Screenplay Assignment
- [ ] Create Title Page (use `titlepage_template.md`)
- [ ] Translate narrative into screenplay format
- [ ] Ensure correct sluglines
- [ ] Ensure correct action formatting
- [ ] Keep screenplay silent (no dialogue)
- [ ] Length: 1–3 pages
- [ ] Export/submit to Canvas
